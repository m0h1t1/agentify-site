How it works

Point it at your API. That's the setup.

1

Connect a system

Hand it your OpenAPI spec. Every endpoint becomes a tool the agent can call.

2

People sign in as themselves

Employees connect through your SSO. Each credential is used only for that person's requests.

3

Reads flow, writes wait

Anything that changes data is held until a human approves it. Then it runs, and it's logged.

Why it's safe

The agent never touches a credential.

The model picks the action. A separate broker picks whose credential goes on the wire.

✓
Per-user identityEvery call runs as the employee who asked. No shared robot account.
✓
Approvals bound to the requestFingerprinted on method, path, and body. Single use. Expires in 15 minutes.
✓
Sandboxed code, no internetAgent-written code runs in a locked container that can reach the broker and nothing else.
✓
Replayable audit logEvery call, held write, and approval, with secrets redacted.

Prompt injection becomes boring.

Hidden instructions in data the agent reads can, at worst, trigger a different approved action. Same person, still needs approval, still logged. There is no credential to steal.
