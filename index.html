How it works

Point it at your API. That's the setup.

Agentify reads your existing API documentation and generates the tools your agent can use. No custom integration code per system.

1

Connect a system

Give Agentify your OpenAPI spec. It builds a catalog of every endpoint and turns them into tools an agent can call.

2

People sign in as themselves

Employees connect through your existing SSO. Each person's credential is stored encrypted and used only for their own requests.

3

Reads flow, writes wait

Anything that changes data is held and shown to a human with the exact payload. Approve it and it runs immediately. Every step is logged.

Why it's safe

The agent never touches a credential.

The model decides which action to take. A separate broker decides whose credential goes on the wire. The two are never in the same place.

✓
Per-user identityNo shared robot account. Every call runs as the employee who asked.
✓
Approvals bound to the exact requestWe fingerprint the method, destination, and body. Approving one thing can't execute a different thing. Single-use, expires in 15 minutes.
✓
Sandboxed code, no internetWhen the agent writes code, it runs in a locked container that can reach the broker and nothing else.
✓
Replayable audit logEvery tool call, held write, and approval, with secrets redacted. Answer "what did the agent do?" in seconds.

If someone hides malicious instructions in data the agent reads, the worst case is a different approved action, still as the same person, still needing approval, still logged.

It cannot escalate to a more powerful credential, because it never had access to any credential in the first place. Prompt injection becomes boring instead of catastrophic.

Inside the console

Every action, on the record.

This is the admin console, running against a demo backend. Nothing here is a mockup.

console · audit

Audit replay. One run, start to finish: two reads pass straight through, the write is held, a human approves it, it executes. Request and response bodies are stored with secrets redacted.

console · approvals

Approvals queue. The exact method, path, and body the agent wants to send. Approve it and it runs. Single use, expires in 15 minutes.

console · integrations

Integrations. Which systems the broker may call and how each person authenticates to them. Per-user SSO or a shared key, encrypted at rest.
